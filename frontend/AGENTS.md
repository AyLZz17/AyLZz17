# AyLZz17 Portfolio

Static portfolio built with Astro. Keep content in `src/data/portfolio.ts`, reusable page structure in `src/layouts` and `src/components`, and the home page in `src/pages/index.astro`.

## Commands

- `pnpm dev` starts the local development server.
- `pnpm build` generates the static site in `dist/`.
- `pnpm preview` previews the production build.
- `pnpm format` formats project files with Oxfmt.

The site uses Astro components and plain CSS; do not add a client-side framework unless a feature requires it.
